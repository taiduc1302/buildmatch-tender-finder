# TENDER_FINDER Quickstart

## Manual Email Alert Import

1. Run `setup_venv.bat` once.
2. Open TENDER_FINDER with `Launch_TENDER_FINDER_GUI.bat`.
3. In `Email Alert Intake`, click `Create / Open Email Import Folder`.
4. Save or copy approved `.eml` alert files into the opened inbox folder.
5. Click `Test Email Import`.
6. Review parsed, rejected, duplicate, and civil/open counts.
7. Click `Run Demo With Email Alerts`.

You can also click `Select Existing Email Folder` to use a OneDrive or other local folder instead of the package-local inbox.

## Fast Demo

Run `run_tenderfinder_demo_fast.bat` when you want a quick workbook rebuild without live public-site fetching.

## Full Demo

Run `run_tenderfinder_demo.bat` when you want the live public tender sweep plus Email Alert Intake.
