`TENDER_FINDER_Tender_Intelligence_Working_Master_TEMPLATE_v1.xlsx` is a
**sanitized template** rebuilt from the original working master:

- **Kept in full (sanitized):** instruction/config sheets (README_START_HERE,
  Dashboard, Config_Scope, Lists, Automation_Plan, Phased_Rollout, Prompt_Pack,
  Cleanup_Log, Project_Plan, Priority_Monitoring, Paid_Intelligence,
  Replacement_Candidate_Review) and the **Source_Register** (~160 public
  sources) + **Municipal_Coverage** sheets — these document public data
  sources and methodology.
- **Data rows removed:** Active_Tenders (200), Future_Projects (200),
  Rejected_Archive (200), Weekly_Review_Log (100), Backup_Raw_Imported (423) —
  these contained real tracked opportunities. Headers were kept and a few
  clearly-marked SYNTHETIC example rows added.

The filename intentionally matches the
`TENDER_FINDER_Tender_Intelligence_Working_Master_*.xlsx` glob that the demo
builder's final-review stage uses to locate the master.

The original folder also contained two earlier master versions (v6,
v7_source_expanded); they were excluded as redundant real-data copies.
