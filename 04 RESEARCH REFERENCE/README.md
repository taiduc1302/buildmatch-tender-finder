# Example Civil Contractor — Tender-Finding Agents — пакет проекта
_Собрано: 19-20 июня 2026_

## Содержимое папки

| Файл | Что это |
|---|---|
| `Autonomous_Tender-Finding_Agents_for_TENDER_FINDER...pdf` | **Исходный документ.** Первый build-план от другого источника: общая идея двух агентов (Active Tenders + Future Projects), стек Make.com + Claude API, обзор BC-тендерных порталов. Отправная точка обсуждения. |
| `TENDER_FINDER_Agent2_Research_Report.md` | **Глубокое исследование Агента #2** (Future Projects). Два горизонта (1-3 мес и 6-18 мес), реальные источники данных по Lower Mainland муниципалитетам, сравнение AI-архитектур (Gemini Deep Research / Perplexity / Claude Cowork / гибрид), стоимость, риски, рекомендации. |
| `TENDER_FINDER_Agent2_Data_Sources_Map.md` | **Карта источников, проверенных вживую.** Что реально открылось при тестировании: Vancouver Open Data (работает), CivicInfo BC RSS (работает), Surrey GIS FutureWorks (заблокирован для внешних IP — нужен тест с локальной сети). Конкретные endpoint'ы и слои. |
| `tenderfinder_agent2.py` | **Рабочий прототип скрипта.** Тянет данные (Vancouver сейчас, Surrey — после теста доступа), скорит через Claude API или офлайн-эвристику, пишет в Excel/CSV + утренний отчёт. Проверен в demo-режиме. |

## Как менялась идея по ходу разговора (коротко)

1. Начали с готового PDF-плана (Make.com + email alerts + Claude API).
2. Решили разделить два агента и сфокусироваться отдельно на **Агенте #2** — future projects.
3. Сделали глубокое исследование → выбрали гибридную архитектуру: структурированные API в основе + LLM deep research поверх для "мягкого" горизонта.
4. Прежде чем строить — попробовали найти и прогнать **реальные** данные Surrey вручную → нашли золотую жилу (`FutureWorks` GIS-слои: Sanitary/Storm/Water/Roads/Drainage) и сразу увидели, что Surrey-сервер закрыт для внешних IP.
5. Собрали это в карту источников + написали и проверили рабочий скрипт-прототип на том, что доступно уже сейчас (Vancouver Open Data), с готовым Surrey-адаптером на будущее.

## Незакрытые шаги (что делать дальше)

- [ ] **Тест №1** (см. карту источников) — открыть Surrey FutureWorks URL с рабочего компа TENDER_FINDER, не из облака. Решает, можно ли автоматизировать главный источник.
- [ ] Если Surrey закрыт — попробовать публичный `opendata-surrey.hub.arcgis.com` (Тест №2) или запросить доступ у города.
- [ ] Запустить `tenderfinder_agent2.py --demo` локально, убедиться что всё работает.
- [ ] Получить `ANTHROPIC_API_KEY`, прогнать `--source vancouver` на реальных данных.
- [ ] По итогам решить — строить ли Агента #1 (active tenders) по той же логике, или начинать с других муниципалитетов (Langley Township, Maple Ridge — у обоих есть ArcGIS-хабы, см. research report).
